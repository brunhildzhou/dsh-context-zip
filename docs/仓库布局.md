# 仓库布局

仓库根是一个发布包：解压即包含插件本体、文档、证据与许可，不含 `node_modules` 与内部开发资料。

| 位置 | 内容 |
|---|---|
| `README.md` | 中文落地页 |
| `README.en.md` | 英文落地页 |
| `RELEASE-NOTES.md` | 本次发布的说明（含相对上一版的改动） |
| `LICENSE` | MIT 许可全文 |
| `dsh-context-zip/` | 插件本体：宿主半边、浏览器半边、包内压缩引擎、行重定向包、构建脚本、安装器与测试套件。要装进 profile 的就是这一份 |
| `docs/功能文档.md` | 功能与代码位置的索引 |
| `docs/结构与文件职责.md` | 逐文件说明各自负责什么 |
| `docs/安装与卸载.md` | 安装器参数、卸载与回滚 |
| `docs/局限性与已知问题.md` | 边界、已知问题与其依据 |
| `docs/同类插件对比.md` | 与同类插件的对照，含本插件不如别人的地方 |
| `docs/截图清单.md` | 落地页截图的来源、口径与逐张验图记录（图归档在 `docs/images/`） |
| `docs/开发说明.md` | 插件目录原来的 README：快速开始、目录结构、构建与测试、开发中发现并修掉的问题 |
| `evidence/套件说明.md` | 测试套件怎么跑、覆盖什么 |
| `evidence/对照测试方案.md` | 压缩效果对照测试的方案 |
| `evidence/对照测试最终报告.md` | 对照测试的结论 |
| `evidence/token消耗与性价比分析.md` | token 消耗的统计 |
| `evidence/独立验收报告汇编.md` | 独立验收的原始报告 |
| `evidence/验收台账.md` | 验收切片的状态表 |

安装与验证的完整命令不在这里：安装参数见 `docs/安装与卸载.md`，套件跑法见 `evidence/套件说明.md`。

`dsh-context-zip/README.md` 是落地页的副本，专供 npm 页面使用。npm 只能打包插件目录以内的文件，而文档与图片都在仓库根，所以那一份里的六张图和英文页链接写成 GitHub 绝对地址；仓库根这份保持相对路径。改落地页时记得同步这一份，并确认图片已经在 GitHub 上可见（推送之后才可达）。
