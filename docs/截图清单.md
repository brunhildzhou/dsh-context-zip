## 来源与口径

**1 至 4（面板四态）**：取自一块隐藏虚拟桌面（Xvfb `:90`，1280x720）里的临时 DSH 实例。临时 `DSH_HOME` 用内置 `web` 模板从零搭出，未从任何用户目录拷贝配置；插件为 0.1.5，从源码树安装；实例监听 3190。四个状态是这样造出来的：未生效＝装好插件后把 profile 的重定向槽位挪走；正在接管＝用 CDP 把 `POST /dsh-context-zip/wire` 停在请求阶段，客户端冻结在写入在途；等待重启＝放行后重定向落盘、戳晚于进程启动时间；已生效＝同一份 home 重启一次。截图用 CDP 按弹窗根元素矩形现算 clip，属于元素级取景，天然不含标签页、地址栏、书签栏与左侧会话栏。副行里那句「基于内置 0.1.7-alpha.1，09-23 12:16」是产品自带文案，不是宿主时间戳，保留。

**5 与 6（检索工具与摘要）**：同样在临时 `DSH_HOME` 里，但模型换成一个本地 OpenAI 兼容桩服务（127.0.0.1:3191），它被要求继续时回一次 `history_segments` 调用、被要求摘要时回一段五段式交接文本。压缩流程与工具调用是插件真实机制跑出来的，会话内容是为截图现造的 scratch 素材。这两张只用来展示界面形态，**不作为能力或效果证据**。

## 逐张验过的四项

1. 会话标题、工作区路径、会话号、时间戳：没有用户侧内容；四态图里只有产品自带的后端版本与构建时间文案。
2. 左侧栏、标签页标题、通知气泡：元素级取景，全部不含。
3. PNG 元数据：六张都经 Pillow 重编码，块只剩 `IHDR`/`IDAT`/`IEND`，无 `tEXt`/`iTXt`/`zTXt`/`eXIf`；对字节扫用户名、项目代号、`127.0.0.1`、`319x`、`/home/`、`/tmp/` 均无命中。
4. 图里显示的宿主版本：`0.1.7-alpha.1`，在 `dsh-context-zip/package.json` 的 peer 范围内。
